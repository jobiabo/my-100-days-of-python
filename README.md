🚀 Getting Started
Prerequisites

Make sure you have Python 3 and Git installed.

Check your Python installation:

python3 --version

Clone the repository
git clone https://github.com/jobiabo/my-100-days-of-python.git

Navigate to the project
cd my-100-days-of-python

Explore the code

Browse the directories to find lessons, exercises, assessments, and projects.

Run an individual Python file with:

python3 path/to/file.py


Replace path/to/file.py with the path to the script you want to run.

Some projects may require additional dependencies. Check their instructions before running them.
